Privacy policy

How this platform handles the information you provide.

Summary

This is a demonstration build of a marine conservation research platform. It is designed so that sensitive data never has to leave your device.

Audio recordings

Audio files selected for classification are decoded, resampled and analysed either inside your browser or on the platform API. The browser path never uploads the file. When the server path is used the file is processed in memory for the analysis and is not stored.

Photographs

Images are sent to the API for classification and the file name is recorded against the result so the identification history stays meaningful.

Submitted observations

Observations you submit are written to the platform database and become part of the shared record. They are labelled as platform submissions so they are never confused with independently verified sighting data.

Dashboard access

The researcher dashboard uses the platform API for authentication. Credentials are sent to the API for verification and a session token is held in the browser only.

Third-party components

The GIS explorer loads map tiles from the OpenStreetMap tile servers and the dashboard loads the Chart.js charting library from a public CDN. Those requests disclose your IP address and browser user-agent to those providers.

Sighting records

All occurrence records published here are derived from the Ocean Biodiversity Information System (OBIS), an open-access repository of marine biodiversity data published under its own data-sharing terms.
